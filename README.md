# C# Learning

My C# learning and practice repository. Learning C# step by step through small examples and exercises.

## Topics

* **01 Basics** — Variables, data types, input/output
* **02 ControlFlow** — Conditions, switch, loops, break, continue
* **03 Methods** — Methods, parameters, return values
* **04 Collections** — Arrays, Lists, Dictionary, HashSet, Queue, Stack, LINQ
* **05 OOP** — Classes, objects, constructors, inheritance, polymorphism, abstraction, interfaces
* **06 Important** — static, const, readonly, ref, out, in, params, enum, struct, DateTime, Guid, nullable, access modifiers, IDisposable
* **07 Modern C#** — Nullable types, pattern matching, switch expressions, tuples, records, modern syntax
* **08 Async** — Task, async, await, Task.WhenAll, error handling
* **09 File & Data** — Files, directories, StreamReader/Writer, JSON

## Goal

Build a strong C# foundation before moving to **ASP.NET Core Web API and .NET backend development**.
